# Optional Skills Guide

Read the repository operating rules and [`skills/AGENTS.md`](../skills/AGENTS.md)
first. This directory is for skills that are valuable but too niche or costly
to enable by default.

- Follow the same `SKILL.md` authoring contract as bundled skills.
- Keep dependency and setup burden explicit, with safe install and verification
  steps. Do not move a skill into the default bundle unless it is broadly useful
  and lightweight enough to load for everyone.
